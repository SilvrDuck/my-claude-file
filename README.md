# my-claude-file

Just a place to store the CLAUDE.md file I like to daily drive, or use as base for my projects.

Hosted through cloudflare on [claudefile.com](https://claudefile.com).

## Was making a website for this really necessary?

Yeah, because it was cheap and typing the url in the browser feels faster than finding a previous project to steal it from on disk or github.

## Can I contribute?

To be honnest, this is more representative of my own preferences, but feel free to open a gh issue if you have suggestions, always happy to learn.

## Does this follow best practices?

Kinda, it losely follows the official [anthropic advice](https://code.claude.com/docs/en/best-practices#write-an-effective-claude-md).
